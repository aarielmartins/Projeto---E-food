# 🍔 E-food

Projeto desenvolvido como exercício prático para aplicar conceitos de **React, TypeScript e gerenciamento de estado** na construção de uma plataforma de pedidos de restaurantes, inspirada em aplicações como o iFood.

## ✨ Funcionalidades

- Listagem de restaurantes
- Visualização dos pratos disponíveis em cada restaurante
- Adição e remoção de produtos do carrinho
- Controle da quantidade de produtos
- Cálculo do valor total do pedido
- Formulário de checkout com validação
- Tela de confirmação do pedido
- Interface responsiva
- Consumo de API REST
- Gerenciamento de estado com Redux Toolkit

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- Redux Toolkit
- React Router
- Formik
- Yup
- Styled Components
- HTML
- CSS
- Vercel

## 📦 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/aarielmartins/Projeto---E-food.git

# Acesse a pasta
cd Projeto---E-food

# Instale as dependências
npm install
